# Scientific Constitution

## Thesis

Existence emerges from the ordered triad through an unbounded family of lawful manifestations. Unity is common source-action-stabilization ancestry, recursive inheritance, witnessed crossing, memory, provenance, and no-retune descent—not one identical equation in every domain.

## Ordered roles

```text
CIF = admitted source possibility / modal capacity
QV  = witnessed lawful crossing / compression / selection / actualization
RFL = inheritable qualified memory / stabilized manifestation
```

```text
QV(CIF) -> RFL
```

Remove CIF and there is no lawful source. Remove QV and nothing crosses. Remove RFL and no result becomes inheritable. The roles cannot be merged without losing the emergence mechanism.

## Recurrence

```text
CIF_s -> QV_s -> RFL_s -> M_rec -> CIF_(s+1)
```

`M_rec` is a return path, not a fourth primitive. RFL memory conditions the next source but does not impersonate it.

## Kernel order

```text
triad -> First Action -> recursive kernel -> modal basis -> domain manifestation
```

The kernel is not prior to the triad. A domain modal basis is not a fitting handle.

## Enhancement

The revised N-body proof is integrated at the kernel as a relational completion. Its universal contribution is identity, directed relation, witness, route, gauge distinction, event, branch, conservation, no-loss memory, reopening, and finite-N promotion. Direct body dynamics is activated only where physical prerequisites and witnesses exist.

## Proof order versus physical order

```text
proof:    triad -> First Action -> kernel -> N-body completion -> universe derivation
physical: Big Implosion -> first physical state -> fields/particles/geometry/time -> active many-body systems -> late universe
```

## Failure rule

Preserve evidence of failure, not the failed mechanism. Repairs must descend from internal law and pass new independent consequences.

## Final proof obligation

Every material final object must reopen to:

```text
source -> crossing/action -> witness -> stabilized memory -> causal parent -> numerical execution -> observable
```
