# Evidence and Claim States

Each result records three independent coordinates:

```text
physical_position: A-Q location
evidence_maturity: DESIGN ... PREDICTIVE_LOCK
fidelity: TOY ... GOLD_STANDARD
```

## Evidence meanings

- `DESIGN`: intended object and obligations stated.
- `FORMALIZED`: definitions/laws/claims exact.
- `IMPLEMENTED`: executable implementation exists.
- `VERIFIED`: frozen tests pass at declared scope.
- `PHYSICALLY_EXECUTED`: exact physical parent generated the exact output.
- `ENSEMBLE_VERIFIED`: required resolution/seed/branch ensemble passed.
- `INDEPENDENTLY_REPRODUCED`: separate reconstruction passed without trusting primary conclusions.
- `FROZEN`: content-addressed object immutable.
- `BLIND_VALIDATED`: preregistered public comparison performed.
- `PREDICTIVE_LOCK`: prospective predictions registered before future reveal.

## Claim record

Every closeout states:

1. strongest supported claim;
2. strongest unsupported claim;
3. exact evidence state and fidelity;
4. assumptions and domain;
5. unresolved branches/gaps;
6. falsifiers.
