# Repository Memory Protocol

The repository must let a fresh model resume without reading a long chat.

## Machine memory

- `STATE.json`: current truth.
- `WORK_QUEUE.json`: authorized sequence.
- `memory/SOURCE_REGISTRY.json`: exact source objects.
- `memory/ARTIFACT_REGISTRY.json`: frozen outputs.
- `memory/RUN_INDEX.json`: all runs and outcomes.
- `memory/DECISION_LOG.jsonl`: scientific/architectural decisions.
- `memory/FAILURE_LOG.jsonl`: failures and replay scope.
- `CLAIMS_LEDGER.json`: claims and evidence.

## Human memory

`memory/CURRENT_CONTEXT.md` is generated by the CLI. Never edit it as the sole source of truth.

## Context budget

A new session should need only:

1. README;
2. CURRENT_CONTEXT;
3. active queue item;
4. active module spec;
5. active run files;
6. source excerpts named by the run.

Do not load the whole repository when the active unit does not require it.
