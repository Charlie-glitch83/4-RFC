# Source Authority and Admission

## Authority order

1. Presentation 29 revised and its metadata: triadic emergence and theorem architecture.
2. Revised triadic N-body proof and metadata: relational kernel enhancement.
3. Presentation 30 and reproducibility metadata: universe construction, provenance, observables, and empirical boundary.
4. Canonical revised universe plan and hyper-realism standards recovered from the old repository/library.
5. Exact module plans and accepted run artifacts.
6. Historical preprints, simulations, closeout ledgers, and analyses.

A lower source may specialize but not silently rename or supersede a higher source.

## Admission procedure

Use `python tools/rfc.py admit-source <path> --classification <CLASS> --label <LABEL>`.

The command copies the exact bytes into `sources/frozen/<sha256>/`, updates the source registry, and records the origin. Scientific use still requires the active work unit to admit the object for a specific role.

## Never do this

- cite a missing repository path as if its bytes were present;
- use a summary as a substitute for the source;
- blend lineages by newest timestamp;
- inherit an old PASS without replay and compatibility checks;
- overwrite a frozen source.
