# Empirical Firewall

## Sealed phases

Modules A-O and Q are generative and sealed.

## Open phase

Only Module P may ingest public observational data, and only after Module O freezes the universe and prediction packet.

```text
O -> P
O -> Q
P -/> O
P -/> Q
```

## Public comparison preregistration

Before reveal, freeze:

- target datasets and versions without values where feasible;
- observables;
- selection/window operators;
- statistics and covariance treatment;
- pass/tension/falsifier thresholds;
- baseline comparators;
- missing-data policy;
- claim language.

No post-reveal target deletion, covariance inflation, statistic selection, branch selection, seed selection, or tolerance changes.
