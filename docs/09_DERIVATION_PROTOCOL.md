# Derivation Protocol

For each new law or material object:

1. Freeze exact admitted sources and parent hashes.
2. Define state space, types, units, frames, gauges, and clocks.
3. Identify CIF source content, QV action/crossing, and RFL stabilized memory.
4. Identify inherited N-body mode and relational objects.
5. Derive candidate class from symmetry, dimensions, conservation, causality, covariance, and parent structure.
6. State uniqueness, branch family, or obstruction.
7. Define local admission witnesses and semantic countermodels.
8. Derive coefficients/scales internally or leave them unresolved. Do not insert public values.
9. Prove conservation, positivity, constraint, covariance, and no-loss obligations.
10. Define observables and falsifiers before execution.
11. Freeze the derivation specification.
12. Obtain independent symbolic reconstruction, preferably including Wolfram where useful.

A familiar standard equation may be used only as:

```text
DERIVED_LAW
LIMIT_OR_CORRESPONDENCE_THEOREM
INTERFACE_LAW
COMPARISON_OBJECT
RESERVED_POSSIBILITY
```

Its class must be explicit.
