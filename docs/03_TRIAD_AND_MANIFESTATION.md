# Triad and Unbounded Lawful Manifestation

A manifestation is lawful only when it preserves distinct source, action, and stabilized-memory roles and supplies domain-specific physics.

For domain `D`, basis/realization `b`, scale `s`, depth `j`, route `[r]`, branch `beta`, event history `e`, and cycle `c`:

\[
\mathcal M_{D,b,s,j,[r],\beta,e,c}
\]

belongs to the manifestation family only when its source, action, witnesses, memory, constraints, and provenance are admitted.

\[
\mathfrak M_{\mathcal T}
=
\bigcup_D\bigcup_{b\in\mathfrak B_D}\bigcup_{s,j,[r],\beta,e,c}
\mathcal M_{D,b,s,j,[r],\beta,e,c}.
\]

Finite `N` is an additional axis where constituted entities apply. It is not the definition of all manifestation.

## Countermodels

Reject:

- arbitrary CIF/QV/RFL labels on an unrelated equation;
- target-selected modal basis;
- source and output collapsed into one object;
- QV as a post-hoc score;
- RFL without memory/reopening;
- scalar output that cannot reopen source, witness, and return;
- dormant carrier with hidden backreaction;
- public target used to choose a specialization.
