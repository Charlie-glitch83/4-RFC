A later model should spend its effort binding exact scientific parents, executing the prescribed derivations and computations, interpreting results, and closing gates. It should not spend sessions inventing another architecture or workflow.

## What cannot honestly be precomputed

The bundle does not fabricate scientific objects that depend on exact admitted source bytes, exact recovered parent states, or the results of preceding physical executions. In particular, it cannot predeclare:

- a unique coefficient when the admitted triad and parent state do not determine one;
- a physical initial condition that has not been generated by its parent;
- a passing numerical result before executing the frozen solver and convergence matrix;
- a K-L-M fixed point when the lawful outcome may instead be a cycle, attractor, branch family, obstruction, or nonconvergence;
- empirical agreement before the universe is frozen and Module P performs read-only comparison.

Those omissions are deliberate scientific safeguards, not unfinished planning. Every such value has a binding slot, provenance requirement, derivation duty, and hard stop.

## Operator responsibility

The work model must use the exact active recipe, Wolfram code, solver template, binding sheet, and gate. It may implement a mathematically required extension only when the active recipe explicitly calls for it and the extension is derived from admitted parents without observational calibration.

When the source law underdetermines a choice, the correct output is a lawful branch family, unresolved freedom, or obstruction. The model must not guess the familiar physical answer.

## Meaning of manufactured PASS

Manufactured examples prove that the reusable code paths, invariants, error handling, manifests, and runner interfaces work. They are not physical RFC universe outputs and may never be promoted as such.

## Meaning of completion

The final universe exists only when one exact, content-addressed lineage has passed physical execution, componentwise convergence, conservation, uncertainty/covariance, restart/replay, independent reconstruction, observer-product generation, immutable freezing, isolated empirical comparison, isolated terminal evolution, and clean-checkout reconstruction.

## Distribution integrity versus live repository state

`BUNDLE_MANIFEST.json` proves the downloaded bootstrap archive before installation. The repository is intentionally mutable after BOOT-000, so later source admission, context refresh, runs, commits, and scientific outputs will change tracked bytes. From that point forward, integrity is governed by verified Git commits, source and artifact manifests, run output manifests, checkpoint/replay hashes, and the immutable Module O freeze.
