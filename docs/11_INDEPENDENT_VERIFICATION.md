# Independent Verification Protocol

The verifier must not trust primary gate summaries, closeout conclusions, cached derived products, or hidden state.

It reconstructs from:

- exact admitted sources;
- exact parent packets;
- frozen definitions and methods;
- independent code or symbolic route where critical;
- declared environment.

It must test:

- object identity and hashes;
- dimensions/types;
- conservation/constraints;
- witnesses and branch classification;
- numerical convergence;
- restart/replay;
- claim boundary.

The verifier records disagreements as first-class results. A primary PASS plus independent FAIL is not averaged; the run remains unresolved.
