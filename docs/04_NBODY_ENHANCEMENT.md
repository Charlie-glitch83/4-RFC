# N-body Enhancement Contract

The N-body proof is the initial integration point because it uses the triad kernel and supplies a mature constructive relational body.

## Inherited package

- typed constituent identity;
- directed lane identity `L(i|j)`;
- local witness/admission evidence;
- route construction;
- gauge-equivalent versus physically distinct route separation;
- events, collisions, transitions, and branches;
- conservation and source-transfer ownership;
- no-loss representation;
- recursive memory and reopening;
- controlled `N -> N+1` promotion;
- uncertainty, provenance, and claim boundaries.

For finite `N`:

```text
lane_count = N(N-1)
lane_increment = 2N
```

Lane growth is relational capacity. A new physical solution requires a witnessed, admissible, non-gauge-equivalent closure.

## Scope

The relational grammar may be universal. Direct Newtonian, relativistic, kinetic, continuum, or field dynamics is domain-specific. Every module declares `DORMANT`, `RELATIONAL_GRAMMAR_ACTIVE`, or `DIRECT_MANY_BODY_ACTIVE`.
